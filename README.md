# GongSiDingWei
公司定位

本仓库沉淀公司的战略定位纲领。

- [公司战略定位（十年纲领）](./公司战略定位.md) —— 定位、使命、愿景、价值观、产品架构、渗透路径、定价与落地清单（内核层，十年不变）
- [产品清单与依赖矩阵](./产品清单与依赖矩阵.md) —— 产品主数据（SSOT）：能力、依赖关系、交付重度、独立销售能力、旗舰包构成与三年路线图
- [定价与阶梯打包方案](./定价与阶梯打包方案.md) —— 五级阶梯的具体产品配置与标价测算、先用后付设计、100 万集团方案、交付成本落地机制
- [产品方案与成交作战手册](./产品方案与成交作战手册.md) —— SKU 阶梯、成交场景矩阵、销售动作、线上获客与三条成交主线 SOP（战术层，每年迭代）
- [线上直播与公域流量方案](./线上直播与公域流量方案.md) —— 公域打法、直播五种场型、主播编制与激励、内容矩阵、全链路与单位经济模型（战术层，每季度校准）
- [线下峰会落地执行手册](./线下峰会落地执行手册.md) —— 首场峰会的规模测算、时间倒排、邀约、议程修订、角色分工、话术改造、预算与复制路径（执行层）
- [AI 提货宝裂变增长方案](./AI提货宝裂变增长方案.md) —— 通知版定价、先用后付、四条裂变链路、裂变系数模型与法律效力边界（单产品增长专项）
- [竞对分析：找钢网](./竞对分析-找钢网.md) —— 竞对战略全貌、七维对比、我方六项劣势、唯一性表述修正、防守打法与全员话术库（每季度复核）
- [营销组织架构与绩效设计](./营销组织架构与绩效设计.md) —— 五个中心的定位与边界、各中心 KPI 与"不该考核"清单、六项跨部门机制、编制路线图与岗位改造（每半年校准）
- [总裁与创始人激励机制设计（第二版）](./总裁与创始人激励机制设计.md) —— 五层结构（底薪/**按毛利计提的增量提成**/经营改善奖金池/**4% 期权分段授予**/组织建设考核）、毛利率三重闸门、权责边界、谈判弹性表与投资人沟通框架（须经律师与税务顾问审定）

> 十份文件的关系：战略定位定方向，产品清单是唯一权威的产品口径，定价方案定价格与打包，作战手册负责成交体系，直播方案负责线上流量与前端变现，峰会手册负责线下活动落地，提货宝方案负责单产品裂变，竞对分析负责差异化与话术，**组织设计负责让前面八份文件有人执行，激励机制设计负责让执行的人有动力且不失控**。
>
> **产品信息变更时，先改产品清单；对外唯一性表述与竞对话术变更时，先改竞对分析；职责与考核变更时，先改组织设计。**
