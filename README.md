# GongSiDingWei
公司定位

本仓库沉淀公司的战略定位纲领。

- [公司战略定位（十年纲领）](./公司战略定位.md) —— 定位、使命、愿景、价值观、产品架构、渗透路径、定价与落地清单（内核层，十年不变）
- [产品清单与依赖矩阵](./产品清单与依赖矩阵.md) —— 产品主数据（SSOT）：能力、依赖关系、交付重度、独立销售能力、旗舰包构成与三年路线图
- [定价与阶梯打包方案](./定价与阶梯打包方案.md) —— 五级阶梯的具体产品配置与标价测算、先用后付设计、100 万集团方案、交付成本落地机制
- [产品方案与成交作战手册](./产品方案与成交作战手册.md) —— SKU 阶梯、成交场景矩阵、销售动作、线上获客与三条成交主线 SOP（战术层，每年迭代）
- [线上直播与公域流量方案](./线上直播与公域流量方案.md) —— 公域打法、直播五种场型、主播编制与激励、内容矩阵、全链路与单位经济模型（战术层，每季度校准）

> 五份文件的关系：战略定位定方向，产品清单是唯一权威的产品口径，定价方案定价格与打包，作战手册负责线下与成交执行，直播方案负责线上流量与前端变现。**产品信息变更时，先改产品清单，再改其余四份。**
