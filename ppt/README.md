# PPT 生成说明

## 产物

- **`../货袋子平台销售培训.pptx`** —— 44 页，16:9 宽屏，可直接在 PowerPoint / WPS 打开并编辑。

## 如何重新生成

内容有更新时，改 `build_huodaizi_deck.py` 里对应的数据，然后：

```bash
pip install python-pptx
cd ppt
python3 build_huodaizi_deck.py
```

## 内容来源

正文口径以 **《[货袋子平台销售话术手册](../货袋子平台销售话术手册.md)》** 为准。
**手册是唯一权威版本，PPT 是它的培训版**——手册改了要同步改这个脚本，不要只改 PPT。

## 使用建议

- **章节页**可作为培训的休息与提问节点；
- **金句页**（第 5、7、10、13、15、31 页）是要求逐字背诵的内容，建议让学员当场复述；
- **异议页**橙色边框为必考条目（第 1、2、4、5、8 条）；
- 第 43 页随身卡建议**单独导出并双面打印**发给每位销售。
